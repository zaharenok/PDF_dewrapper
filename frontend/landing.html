Powerful Document Processing Features

Everything you need to fix document images

📖

Page Dewarping

Straighten curved and warped pages using advanced cubic sheet modeling. Perfect for book scans and folded documents.

  • ✓ Cubic spline algorithm
  • ✓ Automatic curvature detection
  • ✓ Preserves text quality
  • ✓ Works with complex curves
🔄

Deskewing

Automatically detect and correct tilt in scanned documents using Hough transform and projection analysis.

  • ✓ Hough line detection
  • ✓ Projection profile analysis
  • ✓ Sub-degree accuracy
  • ✓ Batch processing
🎯

Perspective Correction

Fix perspective distortion in photos of documents taken at angles. Automatic corner detection and transformation.

  • ✓ Auto corner detection
  • ✓ Perspective transform
  • ✓ Document boundary finding
  • ✓ Smart cropping
✨

Image Enhancement

Improve image quality with denoising, contrast enhancement, sharpening, and adaptive thresholding.

  • ✓ Noise reduction
  • ✓ CLAHE contrast enhancement
  • ✓ Adaptive thresholding
  • ✓ Brightness optimization
